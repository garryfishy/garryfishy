## 🧭 How I Think About Software

I like technology, but I'm more interested in **what it enables**.

Good engineering isn't just:

> “Can we build this?”

It's also:

> “Should we build this?”
> “Does this solve the actual problem?”
> “Can someone else maintain this six months from now?”

I enjoy working somewhere between **engineering, product, architecture, and leadership**.
